* **Importing a walking test helper no longer makes a file a whole-tree judge; reaching the helper's walk of the root does (GOH.CLONENOTJUDGE).** `tests/_tree_clone.py` walks the templates it builds, never the checkout, yet every file importing it was a standing tree reader that each land's pre-step ran (about 355-378 s serial on three recent diffs). `lib/tree_walk.py` sorts each helper def by what its walk reads: the root, or only the parameters it is handed (and which ones). A file reads the tree through a helper only when it uses a root-walking def or hands a walked parameter a path rooted at the checkout (`census(REPO_ROOT / "tests")` still counts). On an empty diff the standing pre-set goes from 545 nodes to 404.
