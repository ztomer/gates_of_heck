* GOH.GRACEWATCH: a grace end is judged on a schedule, release or not. `scripts/grace_watch.py` runs the goh consumers run now over every consumer, under the day and at `GOH_GRACE=over`, whenever any grace end of the tree falls within 7 days (`lib/canary_grace.py` `ends`: every `pub const OVER_FROM` under `crates/goh/src`, the shared one and each scanner's own, such as locale-prefix's 2026-11-30, which the release canary's pass never read). A step red only at the end is recorded under `grace_watch` in the estate state file, naming each undeclared floor as `GOH_<X>_MIN_FILES=N` (`lib/canary_sides.py` reads those lines now, and the canary shows them too). `hooks/claude/estate_advisories.py` says it at session start. `scripts/estate_audit.py`, the daily launchd job, runs it after its audit (`--no-grace-watch` skips it).
