* `required_tools.py --check` judges a pinned tool by its pin again (GOH.PINCHECKFLOOR). GOH.PYTESTPIN turned every pip row into a pin and left `--check` testing only that the tool was present, so a consumer whose box had pytest below the old floor passed every gate that asks (`goh_py_require`, the coverage gate's `need`). In a consumer a pinned tool needs AT LEAST its pin, the floor `--floors` already published to sys_updater; in a goh checkout (the toplevel marker `gates/_self_gate.sh` uses) it needs EXACTLY the pin, judged by `gates/required_pins.py` `off_pin`, the same judgement `--pins-held` makes. A pip row's version is read from its distribution metadata through the gates' interpreter (`-m numpy --version` is no command). ruff stays with `goh_py_ruff_pinned`, whose pin is runner-aware. `tests/test_required_tools_floors.py`, red first through the `--found` seam.
