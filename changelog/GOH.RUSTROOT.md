* The goh binary no longer spawns `git rev-parse --show-toplevel`: `gitroot.rs` reads the repo top level from git's own layout (a `.git` directory, a `.git` file for a linked worktree or submodule, one filesystem, an ordinary config owned by this user) and asks git only for what it does not model (a bare repo, `GIT_DIR`/`GIT_WORK_TREE` and the other steering variables, `core.worktree`, includes, a crossed mount). Parity against git is tested on plain, nested, symlinked, worktree, submodule, bare, inside-the-git-dir and no-repo fixtures; `tests/test_goh_git_spawns.py` now pins zero such spawns from the binary. A land gate ran about 3,100 of them (GOH.RUSTROOT).
