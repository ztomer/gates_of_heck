* GOH.STATEDBS3: goh's small state stores get their goh.db tables (migration 0004, `lib/small_stores.py`): `kv` for the five whole-file JSON stores (the estate audit's state, the pin push ledger and sweep registry, the cache evictor's ledger, wf-pin's consumer pin record), `commit_gated` for the commit-gated ledger and `flakes` for the flake register. Each store's rows live in the goh.db beside its file, so a caller naming its own file (`GOH_ESTATE_STATE`, `GOH_FLAKE_DIR`, ...) has its own database; a file is imported once by sha256 in the first write and read under the rows until then. `small_stores.py import|export [STATE_DIR] [--to DIR]`; on a copy of the live files (2026-11-23: 1,032 commit-gated rows, 15 flake rows, five documents up to 1.1 MB) every store read back equal.
