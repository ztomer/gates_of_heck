* **A land whose main moved only the Rust build inputs re-runs structural and the tests that run the binary, not the whole set** (GOH.PRECODERUST). `Cargo.lock` and `crates/` were counted as the pre-step's own code (`pre_step_code`), so any move there ran the whole pre-land again: 737 + 1,122 + 854 s in three lands of one day, with about 50 min of queue wait behind them. `lib/pre_reuse.py` now answers NARROW for a move to the binary's build inputs alone: the nodes are the tests that run the binary (`binary_runners.choose`, in `readers`), and a `--structural` line makes `lib/land_pre_reuse.sh` run `structural.sh --full` first, as the full pre-step does. A build input moving with the runner's own code (`tools/pytest.sh`, the structural gates) still runs the whole set. `tests/test_pre_reuse.py`.
