* **A house script killed by a signal exits 128+N through the `goh` wrapper, never 2 (GOH.WRAPSIGNAL).** `house_script` (`goh ship`, `land`, `wait`...) and `goh launch-app` mapped a child that had no exit code (a signal death) to 2, which `goh land --wait` also uses for "no request", so a killed wait read as a missing land. `crates/goh/src/exit_status.rs` `code_of` is the one reading (the code, else 128 plus the signal: SIGTERM 143, SIGKILL 137), shared with the step runner that already did this; `tests/cli_signal.rs` kills a fixture `landq.py` through the wrapper. A `--wait` that catches SIGTERM itself still exits 3 (`lib/landq_look.py`, GOH.WAITEARLY), its documented "else". No caller of the wrapper's codes in goh or in loopctl reads 143 as a verdict (all treat any non-zero other than a documented code as failure).
