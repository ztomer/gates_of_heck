* GOH.LANDREADERS: a land record is written as goh.db's typed columns and child rows by name, its document beside them while that column exists (`lib/land_columns.py`), and read from them: a reader names the keys it reads and pays for their columns and child tables alone, and a key it did not name is an error. `goh land --report`, `goh land-reds`, `goh land-profile`, the e2e rows, `goh land --check`'s guards, the coverage carry and the waived rules say the same, byte for byte, on a filled file and on one `goh state backfill` has not filled yet (a row not filled is read from its document). A value of the wrong type reaches no column: it stays in `rest`, said on stderr when it is written and named by `goh state check`. An empty `carry` of a judged land is read back as the list it was: a later land that carries nothing clears an earlier one's lines.
* GOH.LANDREADERS: `goh land-reds --backfill` gives each red with no class its class in its land's own columns, no longer a `red_causes` row; a red that has a class keeps it. A record written with no `at` takes its finish's, or its run's, instant. A record's paths are stored in the file's form and read in both, and the form written replaces a run's row of the other, its child rows with it.
