- perf(push): a `goh ship` push gate builds in the main checkout's own cargo build dir, and a removed land slot takes its build dir with it (GOH.BUILDDIRSHARE). cargo keys the build dir by workspace path, so the push export kept a full second copy of every checkout it pushed (routines 19+11 GB, divoomd 12+11, multitop 22+10). Under `GOH_GATE_CLASS=ship`, when the checkout is clean at the pushed commit and is one workspace, the export's run-dir cargo config names the checkout's build dir (`gates/_push_build_dirs.py --shared`; the repo's own build-dir setting still wins), so the install step that follows builds incrementally; after the gate every tracked file off HEAD gets the current mtime (`--touch-changed`), so an edit made during the build is never judged fresh. `lib/build_dir_reap.py` names the build dirs a checkout uses alone (not the main checkout's, not inside the tree), and `lib/land_slot.py` removes them with a slot past KEEP.
