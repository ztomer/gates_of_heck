* **`goh ship` asks the release commit of its land's gate before the suite, and a dead ship's record gets its terminal status (GOH.SHIPEARLY).** Of goh's 26 release and verify reds since 2026-11-11, 6 were the release commit's own gate (v0.140.3's release text refused 1019 s in), 12 hosted CI at verify and 8 checks retired since. `.gatesrc` now declares `GOH_SHIP_PREFLIGHT='tools/release_goh.sh --preflight {version}'`: the kit makes the release commit in a scratch worktree off HEAD and runs `lib/release_gate.py run` over it, so a red refuses the ship before anything starts, and a green is recorded for that tree (`relset`), so the release land reuses it. A ship result whose worker died saying `running` (two of 2026-11-17 still said so) is rewritten `failed` at `abandoned` by `goh ship --status` and by every ship start in that directory.
