* **The stdin-hang guard judges every filter by one rule (`GOH.STDINFILTERS`).** A reader is now any filter whose argv names no input file -- `grep`, `jq`, `sed`, `awk`, `sort`, `uniq`, `wc`, `head`, `tail`, `cut`, `tr`, `xargs` beside `cat` and `tee` -- judged from each one's argv grammar (its options' values, its script operand, the options that name the input or read none: `grep -r`, `jq -n`, `sed -i`, `xargs -a`, an awk program of BEGIN blocks only), so `grep -c pattern` or `jq .` with nothing piped is refused like `cat > f`. `goh agent-stalls` now names a shell blocked in its own `read` builtin (no child process is the reader) with the shell's pid to kill. Also: an empty quoted word (`grep -c "" f`) no longer splits a command in two in `lib/shell_segments.py`.
