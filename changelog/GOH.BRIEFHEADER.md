* **`goh brief` prints a spawn's header from the rules, and the spawn guard's refusal carries the header that would have passed** (GOH.BRIEFHEADER). 55 spawn refusals in the week to 2026-11-21 were brief headers written by trial (no effort 10, no model 6, general-purpose for write work 10, unknown tags 6, a tier the profile makes `never` 8, the cheap opus tier without its tag 5, a missing `Pool:` line 4). `goh brief --work write|read --tags T,.. [--owner-asked WORDS] [--repo R]` (`hooks/claude/brief.py`) reads `model_choice.json` through `model_choice.load()`, so the active profile and the budget guard's drop are the guard's own, and prints the `Model-choice:` line on the cheapest class the profile accepts, a `Pool:` line when the tier is pool work, `Agent-type:` when a heavy type is asked for with `--type-why`, `Owner-asked:` when given, and the Agent call's model, effort and subagent_type (`--json` as data; `--model`/`--effort` pin a class). Unknown tags are dropped and a tag set no tier accepts is completed (the missing tag of a set it partly declared, else `unchecked` for write, `read-only` for read) with a note saying so. `agent_guard.py`'s choice, pool and agent-type refusals append `Corrected header (goh brief ...)` for the refused prompt, keeping its own Pool, Agent-type and Owner-asked lines. `tests/test_goh_brief.py`: brief's output passes the guard for every tier of pro, max and ultra, and each of the ten refusal shapes, its correction applied, passes.
