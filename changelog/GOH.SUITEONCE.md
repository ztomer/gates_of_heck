* A plain land runs the pytest suite once (GOH.SUITEONCE): when the gate's checkout is the very commit tree its pre-step judged green (`lib/gate_identity.py` `suite`: tree and tools), chosen against the main the gate lands on, the gate's `tools/pytest.sh` takes the pre-step's verdict instead of a run (`lib/pre_reuse.py --suite`): the diff's tests passed on these bytes, every other test passed on main's tree and is carried from its suite record, which must hold all of them; the reuse is one use of the audited `carry` path and writes the tree's own suite record for the next land. The land's ledger row names the verdict (`suite_reused`, `<judged sha>:<suite identity>`). Another tree, base, a missing or incomplete main record, a narrowed or instrumented (coverage) run runs the suite as before. The pre-step stamps its whole selection and base into its record (`tools/affected_tests.py`), and a record names a tree only when its run ended on the bytes it started on (`tests/_land_verdicts.py`, the live-worktree case of GOH.LANDSNAPSHOT). Before: plain lands' gate pytest a median 128 s (max 17.7 min), `suite:carried` runs 13.7-696 s on 2026-11-18 (`goh land-profile`). Instrumented lands still run the coverage suite: their profiles are not passed forward.
