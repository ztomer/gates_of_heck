* **A gate run in a loop lane's worktree takes its slot as `lane` (GOH.LANECLASS).** GOH.SLOTPRIORITY ranked the long lane land > ship > lane > work, but nothing declared `lane`: a lane's `tools/pytest.sh`, `land --check` and push gates all queued as `work`, behind the pin sweep's consumer pushes. The class is now derived from where the gate runs instead of asked of each lane: a checkout under the loop's lanes root (`$LOOPCTL_LANES_ROOT`, else `$XDG_STATE_HOME/loop/lanes`, else `~/.local/state/loop/lanes`) is `lane` unless its caller declared another class (`lib/gate_lanes.py` `default_class`; `lib/gate_slot.sh`, `lib/admission.py` and `tools/pytest.sh` take it, `lib/gate_slot.py default-class` prints it). An explicit `GOH_GATE_CLASS` wins, so a land's gate in a lane worktree is still `land`; the wait shows as `slot wait lane` in `goh land-profile`.
