* A failing test no longer prints the whole process environment into a log. `tests/test_proven.py`'s `env` fixture printed every variable, the session's account id included, in a failure's header and in its assertion's `where` line; it and `hermetic_env()` now return `PrintSafeEnv` (`tests/env_probe.py`), which prints only the variables a test names. `tests/test_no_env_dump.py` now also refuses a fixture that returns an unredacted environment, a test's use of one, a copy of one inside an assertion, and an f-string that formats one (GOH.PROVENENVDUMP).
