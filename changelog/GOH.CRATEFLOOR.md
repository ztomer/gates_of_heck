* Rust coverage: the floors file (`GOH_COV_FLOORS_JSON`) takes `crate_floors` and `file_floors` -- each entry `{"floor": N, "reason": "..."}` lowers ONE crate or file below the uniform floor while the rest stay at it, and `GOH_COV_FLOOR_RUST` and the floors file now work together (the file was passed only when no uniform floor was set). An entry without a reason is refused, one at or above the uniform floor or naming no crate or file fails as stale, and the file's content keys the coverage reuse (`gates/_lcov_floor_maps.py`, GOH.CRATEFLOOR).
