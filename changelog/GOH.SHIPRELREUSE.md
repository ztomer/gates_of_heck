* **goh's version is its release tag.** `goh --version` now says what `lib/goh_version.sh` reads from git: `X.Y.Z` on a commit tagged vX.Y.Z, `X.Y.Z-N-g<sha>` past one (`-dirty` with uncommitted inputs), `unknown` with no release tag, never a number from a file. Cargo.toml's version is a fixed `0.0.0` placeholder nothing reads, so `tools/release_goh.sh`'s release commit changes only CHANGELOG.md and the fragments it folds, and the land verdict of the tip it was cut from covers every byte a build or a test reads (GOH.SHIPRELREUSE). The build store, `scripts/build-goh.sh`, the gate's binary-currency check and gohpin's own release all ask that one script; a tagged commit's source stamp ends in ` vX.Y.Z`, so a release's build is never the untagged build of the same trees. `goh tag-version` gains a `changelog:` source (the newest `## vX.Y.Z` heading), which goh's own .gatesrc now names.
