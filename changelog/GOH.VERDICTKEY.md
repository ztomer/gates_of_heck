* **A verdict is keyed by what judged it, not by the tree alone.** `lib/gate_identity.py` is the one identity: the gate mode or command, the content of the gates that ran, and every tool a step may invoke (rustc, cargo, python, swift, shellcheck, ruff, cargo-llvm-cov, xcodebuild, by the binary PATH finds). A proven step is keyed on it, so another shellcheck first on PATH re-runs the step instead of answering "proven ... skipped"; a loaded verdict is `goh-loaded/<tree>-<identity>.json`, so green under one command is no verdict for another; and `tools/land.sh` writes `<sha> <identity>` to goh-landed, so the release push rule reuses only a parent the full gate landed under today's gates and tools -- a hand-set `GOH_LAND_GATE=true` lands, but its parent verdict is refused (GOH.VERDICTKEY).
