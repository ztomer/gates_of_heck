* **The loaded run runs only the tests load can turn.** `tools/loaded_suite.sh` (the run each land starts on its tip and every ship waits for) ran all ~5400 tests under 16 spinners, 455-516 s; it now runs `pytest -m load_sensitive`, the ~500 tests whose verdict can move with the box's load. `tests/load_sensitive.py` derives them from the source (a sleep, a clock read, a GiveUp poll, a process or thread beside the test, a signal, a bounded wait, a deadline handed to the code under test, a literal timeout under 30 s, through helpers, kits and fixtures), and `tests/test_load_sensitive.py` refuses a derived test without `@pytest.mark.load_sensitive`, a mark with neither a signal nor a `reason=`, and any of the 18 load-only failures seen so far (`tests/load_history.json`) outside the set. The land gate still runs every test (GOH.LOADEDSUBSET).
