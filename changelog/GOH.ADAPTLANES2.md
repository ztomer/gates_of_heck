* Adaptive lanes enforce: `GOH_LANE_ADMIT` defaults to `refuse`, and a refused write spawn is a deferral naming what the reading lacked, for the coordinator to re-dispatch. A prompt line `Owner-asked: <words>` starts with no room and is logged `owner`; an unread reading still admits. The ceilings are calibrated from the lane ledger joined with each lane's land (`docs/config.md`): `GOH_LANE_LOAD_PER_CORE` 2.0 -> 2.5 (where a gate's cpu per wall second falls), `GOH_LANE_MAX_WAITING` 0 -> 1, `GOH_LANE_MIN_FREE_GIB` stays 30. Ledger lines now carry the queue item (GOH.ADAPTLANES2).
