* GOH.HOMEPATHHARD: `goh` finds its checkout from `GOH_DIR` (or `GOH`), else from where its own binary sits (the nearest directory above it holding `gates/`), and otherwise stops with exit 2 naming both, instead of falling back to a literal checkout under one person's home directory. A new suite judge, `tests/test_no_owner_home_path.py`, refuses any tracked file naming `/Users/<name>` or `/home/<name>` for a real account (placeholders such as `/Users/me` pass); the launchd plists, which launchd reads without expanding variables, stay on its ratchet with that reason.
