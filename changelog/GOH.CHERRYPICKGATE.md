* **`goh land --check` runs the commit gate on every commit no commit gate judged (`GOH.CHERRYPICKGATE`).** `git cherry-pick` (and a rebase, an am, `--no-verify`) runs no commit hook: an env-spread red cherry-picked into a lane was caught only at land, a whole enqueue cycle later (2026-11-22). `gates/commit_gate.sh` now stamps the tree it passed (`lib/commit_stamp.py`, `$XDG_STATE_HOME/goh/commit-gated.jsonl`), and the land's check runs the commit gate, as that commit's pre-commit would have (a detached worktree at its parent, the change staged), on each commit of the range whose tree carries no stamp, naming it; a red one refuses the check, a green one is stamped. `tests/test_land_check_commits.py`.
