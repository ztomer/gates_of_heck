* **A push export no longer skips a build whose outputs a later step needs, wrapper scripts included (GOH.PROVENBUILD).** A proven step's real run is measured: the ignored entries it made are kept per step string (`gates/_proven_made.sh`), and only a run that began with no ignored file says a step makes nothing. A hit whose products are not here, or that a fresh tree never measured, is hollow: `local_ci.sh` re-runs it when a later step will really run and skips it when none does (a tree proven whole still skips its builds); `proven.sh` re-runs it. CadGoose2's `bash scripts/build.sh Release` needed a hand-written `produces=`; no wrapper build does now.
* **bash no longer crashes mid-measurement on macOS, so a build's products are never recorded as nothing (GOH.PROVENBUILD).** v0.122.0's release gate failed `test_a_build_into_a_directory_an_earlier_step_made_is_its_product_too`: in `proven_made`'s forked group, disposing a bare `LC_ALL=C comm` prefix made bash re-run `setlocale`, and Homebrew bash's libintl called CoreFoundation after fork (SIGSEGV, "single-threaded process forked"), so the group died with $? 0 and the build was credited nothing (2-4 of 48 runs under `-n 12`). goh's shell now sets a locale only through `env LC_ALL=C` (11 sites), and `tests/test_shell_locale.py` refuses any locale assignment bash would make itself.
