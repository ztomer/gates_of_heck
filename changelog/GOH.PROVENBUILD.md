* **A push export no longer skips a build whose outputs a later step needs, wrapper scripts included (GOH.PROVENBUILD).** A proven step's real run is measured: the ignored entries it made are kept per step string (`gates/_proven_made.sh`), and only a run that began with no ignored file says a step makes nothing. A hit whose products are not here, or that a fresh tree never measured, is hollow: `local_ci.sh` re-runs it when a later step will really run and skips it when none does (a tree proven whole still skips its builds); `proven.sh` re-runs it. CadGoose2's `bash scripts/build.sh Release` needed a hand-written `produces=`; no wrapper build does now.
