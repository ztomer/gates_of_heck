- **ship**: a ship's fresh instrumented full run no longer re-runs the tests its tree already judged that run no binary: the suite record keeps `judged` (the passes some run made on this very tree, never one carried to it), and `goh ship`'s suite step runs with `GOH_LAND_VERDICTS_REUSE=@tree`, skipping a node only when it was judged on the tree, ran no binary and an instrumented run measured it running none. Every binary-running, carried or unmeasured test still runs instrumented, so the record stays the full instrumented one the release kit requires and the coverage shadow sees the whole profile. The tests that run no binary were about 73% of the suite's test time (GOH.SHIPBREACH0137).
