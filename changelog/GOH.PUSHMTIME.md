- perf(push): the push export's tree is kept between pushes, so cargo rebuilds only what changed (GOH.PUSHMTIME). A fresh `git worktree add` every push gave every tracked file a new mtime, and cargo rebuilt every workspace crate in every profile the gate uses (monitor 2026-11-15: a no-op release build 50 s, the bench profile 38 s). The run now sets its tree aside unregistered at `<run dir>.kept` (`push_keep_tree`: no extra `git worktree list` entry), and the next run moves its files into a `--no-checkout` worktree, refreshes the index by content and `reset --hard`s, so git rewrites only the files that differ, then `clean -ffdx` (the in-tree `target/` kept). An unchanged push compiles no workspace crate; a one-file change compiles its crate. A ship push sharing the checkout's build dir still builds from a fresh tree; a kept tree goes with its checkout's marker, and the dead-run reaper skips it.
