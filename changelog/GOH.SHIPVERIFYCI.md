* GOH.SHIPVERIFYCI: `goh ship`'s verify step reads a red hosted run whose every failed job died before or after its steps (no runner: the Actions quota spent, cancelled before a step, its log a 404) as `hosted CI unavailable`: advisory over goh's push gate, as a pending run is, so the ship finishes and records the item. A run in which any job ran a step and failed still stops the ship at verify; without the push gate an unavailable run fails, naming it.
