* GOH.COVRUNNER: the Rust coverage gate starts every test binary through the runner cargo would (`gates/_cov_run_tests.py`, the resolver in `gates/_cargo_config.py` beside the `[env]` table). Since GOH.COVPARBINS the gate starts the built binaries itself, and a runner a repo declares in `.cargo/config.toml` never ran: ztools' `tools/cargo_test_runner.sh` sandboxes HOME for its tests, so `test_home_is_sandboxed` was red under coverage and green under `cargo test`. The runner is resolved as cargo's `target_runner` does: `CARGO_TARGET_<TRIPLE>_RUNNER`, else `target.<triple>.runner`, else the one matching `target.'cfg(..)'.runner` (two matching are refused, as cargo refuses them; cfgs from `rustc --print cfg` under the environment's rustflags), a deeper config file winning, a string split on whitespace or an array, a program holding a slash relative to the directory holding `.cargo`; rustc is asked for the triple only when some runner is declared. Pinned by `tests/test_cov_run_tests_runner.py`, whose fixture crate's runner sets a variable its test asserts under `cargo test` and under the gate.
