* A goh lane can no longer pass its land on a gate it weakened. The landing queue drove every land, the enqueue pre-step included, with the lane's own `tools/land.sh`, run from the lane's head export with the lane's gates (GOH.PRESTEPSHARE's enqueue printed a deadline its change had not landed yet); it now always drives with main's `tools/land.sh`, and the lander re-execs when a land changes it. A goh land whose diff changes the gate code or `.gatesrc` is gated twice: under main tip's gates first (its land gate from main's `.gatesrc`), then under the tip's own, so a gate change still proves itself before main moves; a diff that changes neither runs one gate. Ruling: `docs/decisions/D-0012`; pinned by `tests/test_land_driver.py` (GOH.PRESTEPHEAD).
