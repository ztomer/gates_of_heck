* **`goh dead-port`: a test's dead endpoint on a literal ephemeral port is refused (`GOH.DEADPORTSCAN`, class EST.DEADPORT).** ztools' `call_osaurus` test used a literal loopback port (59999) as an "unreachable" endpoint; it is in the OS's ephemeral range, so any outgoing connection (or a server bound to port 0) could be handed it, the endpoint answered, and the test failed at random -- it refused ztools' v0.124.0 pin push. `crates/goh/src/deadport.rs`, a structural step in every repo, reads TEST code only (the house test-path rule, now one shared `crate::unreaped::is_test_path`; Swift's `...Tests` layout; Rust `#[cfg(test)]` regions via the shared `guard::rust_region_lines`) and refuses a literal port in 32768-65535, the union of macOS's 49152-65535 and Linux's 32768-60999, on `localhost`/`127.0.0.1`/`[::1]`/`0.0.0.0`, written `HOST:PORT`, as a quoted host and then the port, or Rust's typed loopback. A service port in non-test code, a port below 32768 and a port read from a socket stay green; `dead-port-ok: <reason>` escapes a line, a bare escape is red. The message names the fix that holds on BOTH OSes: listen on `127.0.0.1:0` without `SO_REUSEADDR`, connect, accept, close the listener and hold the connected pair (ztools 19ed47d `DeadEndpoint::hold`): connects are refused at once, a bind gets `EADDRINUSE`. The brief's first fix, a socket bound and never listening, was measured wrong on macOS: it drops the SYN, so a connect waits out its whole timeout (`docs/contracts.md` section 30). Seeded in `dead_port_seed.json`, floor `GOH_DEAD_PORT_MIN_FILES` (this repo: 580 of 647). Its grace is its own, judged from **2026-12-07** (`deadport::OVER_FROM`, `grace::over_from`, same `GOH_GRACE` seam), because goh's ships were frozen the day it landed: it covers the consumers with sites on 2026-11-15, token-pool (4) and two private consumers (2 sites each: a home-server service and a nested app), which fix, escape (a real service port in a test) or seed them before that day; ztools fixed its 9 itself (19ed47d) and is not covered.
