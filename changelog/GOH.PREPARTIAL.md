* GOH.PREPARTIAL: an enqueue's green set outlives a stop in what follows it. The pre-step runs the tests its land's gate would run (`lib/pre_owed.py`) and the release canary after its set, and a deadline in either threw the set's green verdict away (GOH.NITS3: 1500 s, stopped in the canary). The set's record is now marked green before either starts; `lib/pre_deadline.py` ends such an enqueue with that verdict, and an owed run that was killed or never admitted is no red. The gate runs what was still owed. A set still running, a red one, or a land's own pre-step is no verdict at its deadline, as before.
* GOH.PREPARTIAL: a pre-step killed at its deadline or by a signal leaves no `.judges`, `.owed` or `.mac` file beside its record.
