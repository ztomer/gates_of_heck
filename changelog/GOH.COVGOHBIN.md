- fix(coverage): a test that drives goh through a gate script leaves a profile under the instrumented run (GOH.COVGOHBIN). The suite's coverage run names its instrumented goh (`GOH_COV_GOH`, `.gatesrc` `GOH_COV_RUST_EXTERNAL`) and `gates/_goh_bin.sh` answers with it whenever it says it was built from the source the resolution wants, never for other source or `dirty`; a parent's answer made without it is not inherited, and a hermetic test child keeps the variable. 635 tests (1,322 test-s) had run the by-stamp release build, so no run stored their profiles and `lib/bin_reach.py` chose them for every Rust change.
