* GOH.SHIMNESTED: `tests/test_suite_sccache.py` no longer asserts that the sccache shim names the TMPDIR the suite started in. Under `local_ci` the step's shim (`lib/step_tmp.sh`, EST.TMPLEAK) is found first and rightly names the user's TMPDIR, while the suite's `real_tmp()` is the step slot, so main's own gate went red on every land. The invariant is now "the TMPDIR handed to the server is outside every temp root a run removes" (`suite_tmp.baked_tmpdir`, `suite_tmp.disposable`: this suite's root, a `goh.noindex/step.NN` slot, a `goh-suite-tmp.*` or `goh-pytest.*` root), calibrated both ways by a parametrized test.
