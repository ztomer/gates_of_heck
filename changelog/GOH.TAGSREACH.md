* `goh changelog-tags` judges only the `v*` tags reachable from the judged commit (`git tag --merged HEAD`; at `--staged`, the commit's parent), so a branch cut before a release no longer fails its commit gate and enqueue pre-step for that release's tag until it is rebased; a reachable tag with no heading still fails, and the shallow-clone NOT JUDGED refusal is unchanged (GOH.TAGSREACH).
