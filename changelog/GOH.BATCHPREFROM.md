- **land**: the lander's batch gate reads the enqueue's kept pre-step verdict (`GOH_LAND_PRE_FROM`) when the tree it gates is the enqueued commit's tree, so a lone item after a bisect no longer re-runs the whole pre-step; a stacked tip is still judged again. A kept verdict no gate read is removed when its request is recorded, so the queue's `pre/` stops growing. Each land's coverage decision (`measuring -- WHY` or `reused`) reaches the land's log through the gate's follower and is named per item in lander.log; `lib/pre_fast.py` counts a `.gatesrc` change as a coverage input only where a `GOH_COV_*` (or exported `GOH_`) line moved (GOH.BATCHPREFROM).
