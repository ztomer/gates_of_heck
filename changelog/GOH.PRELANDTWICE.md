- A land runs its pre-step once when main moved only where no test reads: `goh land --enqueue --land` keeps its green verdict on the request, and the lander's `tools/land.sh` reuses it (or its own earlier run's, after main moved under the lock) when every path between the judged commit and the rebased tip is read by no test (`lib/pre_reuse.py`, asking `tools/affected_tests.py` `readers`, the selection's own notion); moved paths some tests read run those tests alone (`--readers-only`), and a path both sides changed, a moved pre-step input, or a missing or unreadable kept verdict runs the whole set. The land log names the verdict, the sha it was judged at and the paths that moved.
