* **`goh stop` owns by agent session, not by shell (GOH.STOPOWNSHELL).** Each Bash call is a new shell, so an agent's own earlier `cmd &` was refused. `lib/session_owner.py` reads `CLAUDE_CODE_SESSION_ID` from a process's start environment: `goh stop` accepts this session's processes and still refuses another session's, and the kill-by-name refusal names `goh stop` only for pids it would accept (the stamp route otherwise).
