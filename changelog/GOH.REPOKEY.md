* GOH.REPOKEY: goh's stored paths and repos read the same in two forms. `lib/state_paths.py` (and `crates/goh/src/goh_config.rs` for the binary) names the state root, the repos root and the loop's queue from `GOH_STATE_ROOT`, `GOH_REPOS_ROOT`, `GOH_LOOP_QUEUE`, else `config.toml`, else the defaults; every seam takes its default from them, so the ship directory follows `XDG_STATE_HOME` as goh.db did. A path column may start with `$STATE`, `$REPOS` or `$HOMEDIR` and a repo may be its key: each store's readers take both forms, and its own insert writes tokens only once the file's `meta.paths` says `token`; text is never touched.
