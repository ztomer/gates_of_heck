* The coverage step's external part builds one instrumented binary from any checkout of a tree: its workspace root is remapped out of the coverage map (`--remap-path-prefix`, the report's names put back under the checkout) and it carries no debug info, whose debug map named every object in the checkout-keyed build dir; one tree had built 131f8444 in one lane and 8218270f in another, so no profile keyed on the binary could be reused across lanes. The build is also faster (goh: 26 s against 37 s) (GOH.COVCARRY3).
* An instrumented land now carries a binary-running test across trees when its diff leaves the instrumented binary's bytes alone: each test's merged profile is kept under (repo, tree, tools, the binary's content hash) (`lib/prof_store.py`), and a node `tools/affected_tests.py` does not choose is deselected with its stored profile linked where the coverage report reads it, so the floor still judges a complete profile; it is kept again under the new tree. `GOH_PROFCARRY_TESTS=off` is the kill switch; the `profcarry` audit and the fresh full instrumented run before every ship stay (GOH.COVCARRY3).
* The `profcarry` audit's noise band is measured, no longer guessed: two full instrumented runs of one set of Rust inputs (a land's claim on one tree, a lane's run of another with the same Rust) covered the same lines in every crate (goh 26844/27517), so a fresh run now agrees with a claim only on equal covered lines; the guess forgave 13 of goh's lines (GOH.COVCARRY3).
