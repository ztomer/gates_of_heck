* GOH.OLDWRITERS: an older copy of goh goes on writing goh.db and goh-cache.db past a newer schema number when that number is in `meta.old_writers_safe` (`lib/db_core.py` `newer`, a set check: a `refuse` number is never hidden by a `safe` one after it). A schema file says so on line 1 (`-- old-writers: safe` or `refuse`), and `lib/db_safe.py` judges it: additive statements only, triggers keyed to their own row, a remade view's columns equal in order, replayed in memory. An older copy never sweeps such a file.
* GOH.OLDWRITERS: a sweep loses no row. The archive's `INSERT OR IGNORE` also skipped a row the archive refused (a NOT NULL column the live table had dropped) and the live row was deleted; now each leaving row is found whole in the archive first, under the live file's write lock, `-- with:` child rows leave with their parent's, and a part whose shape differs in any column or child table is closed and `-b` opened (`lib/db_bounds_with.py`).
* GOH.OLDWRITERS: `goh state contract N` applies a by-command schema number (no open does), the file copied under the write lock first; `goh state olds --since X` names every process, worktree and installed binary that still runs goh without commit X.
* GOH.OLDWRITERS: every INSERT in `lib/`, `tools/`, `hooks/`, `gates/` and `checks/` names its columns (`tests/test_db_old_writers.py`). SQLite older than 3.44 is refused by name.
