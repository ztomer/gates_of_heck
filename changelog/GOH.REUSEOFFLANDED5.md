The disagreement was real, not a mis-sample: `lib/release_gate.py` `names` took `tools/affected_tests.py` `readers`, which leaves the tree readers out, so the release set never ran a judge of the release text beyond the structural gate, and an unsampled push would have sent a red commit. `names` now adds `TEXT_JUDGES` (the self-walk, about 50 s), so d0d40569's release land refuses at the same red; `test_every_text_judge_is_a_tree_reader_that_exists` keeps the list honest.
