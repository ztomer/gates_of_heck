* An instrumented land does not choose its binary-running tests by per-test coverage maps: rustc's coverage hash covers a function's own body, so a change to a const or table it reads keeps the hash and a reused profile credits a branch the new binary never takes; 25 of the last 40 Rust commits change such lines. The maps are cheap (median 61 of 3846 functions per test, 23 ms and 19 KB each), so the speedup is filed as same-binary profile carry under a fresh instrumented full run before every ship.
