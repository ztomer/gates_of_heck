* GOH.DEVSWAP: the release kit's dev install (`tools/release-kit/update_dev.sh`) stages, verifies, then swaps. It used to quit the app and remove the installed copy before copying, so a failed or wrong ditto left no app, nothing running, and the words "nothing installed". The new copy is now staged in a hidden directory of the run beside the installed one, read back, de-quarantined and signed there; only then is the running copy quit and the copy swapped in by two rename(2)s (old aside, new in). A failed rename puts the old copy back and relaunches it. A copy that will not quit, a ditto that fails or copies the wrong thing, and a TERM mid-copy all leave the old app running, in place and unchanged, with no staged leftover. A killed run's leftovers are cleaned only once their owner pid is dead, and an old copy it had moved aside is put back. The staged bundle is named `Demo.new`, not `.app`: `lsregister -R` registers an .app even inside a hidden directory and refuses a `.new` (-10811), and keeping the base name keeps codesign's derived identifier for a bundle with no plist. A bundle whose top directory its owner cannot write (EACCES on a rename across directories) is made writable before anything is quit.
