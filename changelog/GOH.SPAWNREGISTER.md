* A spawned lane is registered on its queue item as its Agent call returns: the new PostToolUse hook `hooks/claude/spawn_register.py` (matcher `Agent|Task`) reads the brief's `Item <ID>` and the response's `agentId` and runs `loopctl start` for an in-progress item still `pending-spawn`, so the queue guard no longer refuses a lane's first write (LOOP.STARTID, 7 recurrences). A write that still races it is refused with `registration pending: retry in a few seconds` (GOH.SPAWNREGISTER).
