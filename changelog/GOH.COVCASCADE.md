* **A coverage run starved by failing tests names the tests as its one red cause (`GOH.COVCASCADE`, found by GOH.GRACEFWD).** When the tests a Rust coverage part runs fail (the workspace's `cargo test`, or the `--external` command, which in this repository is the pytest suite), the gate names the failing tests in red and then says, as a warning, that coverage was not measured because those tests starved it; it no longer adds a second red `coverage exports incomplete` line that read as a separate coverage fault. A part that fails anywhere else (the build, the prune, the report) is still an incomplete export. The cpp, py and swift modes already named a test failure as the cause.
