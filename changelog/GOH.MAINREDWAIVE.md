* GOH.MAINREDWAIVE: a test red on main no longer reds an item that did not cause it. goh.db keeps readings of main at a sha (migration 0010, `lib/main_reading.py`): the idle full suite's run of main's tip, and a probe of named tests on a clean checkout of main that the lander takes before a gate when the idle suite found main red and nothing has read main's current tip. A land's runs get `GOH_LAND_WAIVE` (`lib/land_waive.py`), and the suite's plugin (`tests/_land_waive.py`) reports a failing test xfailed only when a reading on main at the run's own base (`git merge-base HEAD <main>`) saw that same test red; the land record's `waived` names each with the reading's id. A test green at the base that the item turns red, a reading at another sha, or a later green reading of the test waives nothing.
