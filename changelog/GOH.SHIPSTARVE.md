* A ship always finds or makes its fresh instrumented full run (GOH.SHIPSTARVE). `goh ship` has a first step, `suite` (lib/ship_full_run.py): when the repo declares `GOH_SHIP_FULL_SUITE=on` and the tip has no instrumented full record, the ship runs the idle lander's instrumented command itself, holding the land lock, in a kept worktree beside its results, admitted as class `ship`; a tip that has its run is skipped, naming whose. Before, only the idle lander made the run and it yields to every land, so a busy queue starved the ship, and a ship that waited for the lock released a main no run had judged (2026-11-18: 8150234a waited 20 min, took 2a3f0dc9, refused). Picked over pinning the idle run because a pinned run still judges a tip the queue then moves past, and releasing anything but main's tip would break the release kit's own contract. The ship record now keeps `land_wait_s` (the queue's time) apart from `own_s` (lock taken to finished), and `goh budget`'s ship row is `own_s`, the wait a field.
