* **A land's gate carries test verdicts across trees (GOH.VERDICTCARRY).** A rebased land re-ran the whole suite (551-731 s at load) because a pre-step's passes counted only on its own tree. Every land's suite now merges its passes into the one store's `carry` path (repo, tree, tools), and the gate deselects a node another recorded tree passed -- the pre-step's commit and main's recorded tip -- when `tools/affected_tests.py` does not choose it for the diff between the trees; tree readers always run, nothing is carried across a change to what every test loads, and no binary test across a build change. One use in ten is the audit's shadow (the carried nodes run anyway; a repeated failure turns `carry` off). Only a run that carried nothing is a full verdict, and `tools/release_goh.sh` refuses a tip without one (`GOH_SHIP_FULL_SUITE`, `reuse.py full-suite`).
