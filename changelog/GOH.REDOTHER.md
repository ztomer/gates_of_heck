* `goh land --report` no longer buries its largest class under `other` (GOH.REDOTHER). Of 146 red lands since 2026-11-20, 73 were `other`: the enqueue-stage reds left their failing node only in the done record's `why` (or in the pre-step log it points at), which `lib/land_cause.py` never read. `classify` now reads the record and that log with the gate log's node rules, and names what it found: `main-moved` (land.sh's "main is at X after the merge"), `killed` (`exit -15`: an agent's exit mid pre-step, not a test), `diff-cov` (the diff-coverage judge), `gate-step` (a gate step failed with no test line: clippy, the file-events ceiling; `detail` names the step), a `gate-test` whose log has no "pre-land green" (the gate and pre-land now run together), and an indented or guard-check structural refusal. `other` is now `unclassified`, a fault of the classifier: the report prints `⚠ unclassified red ITEM (repo day): read LOG` for each, a `gate steps:` line, and the same two in `--json` (`unclassified`, `gate_steps`). The same 146 reds now: 0 unclassified.
