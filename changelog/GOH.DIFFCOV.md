* The Rust coverage gate judges the change, not only the crate (GOH.DIFFCOV): every executable Rust line a change adds or edits must be covered by the same run's report, named `file:line` when not, so a change can no longer add untested lines under a whole-crate floor. `gates/diff_cov.py` is a separate reader of the run's final lcov parts (it never makes or merges them), judging the new side of `git diff -M` from the change's base: `GOH_CHANGE_BASE` for a push, else the merge base with the upstream, then with `main` (a land), then HEAD's parent. Strict where the floor forgives: a zero line inside an executed function is uncovered. Unreachable or other-platform lines go on a reasoned, ratcheted allowlist (`GOH_COV_DIFF_ALLOW`, default `diffcov_allow.json`; stale entries red, reasonless ones refused), never a code-level suppression. `GOH_COV_DIFF=on|warn|off` (default `on`; every consumer with a Rust floor gets it, none had an unpushed Rust change on day one). Swift and C coverage are out of its scope. Measured: 0.26-0.45 s over monitor's 1.1 MB report.
