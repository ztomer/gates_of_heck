- The proven-step cache is under the reuse audit: every hit `proven.sh` or `local_ci.sh` is about to skip asks `lib/reuse_audit.py` first (`gates/_proven_audit.sh`), and one in 16 (one in 4 in a repo that tracks no GitHub workflow, where no hosted CI backs the skip) runs the step anyway and compares it with the reused green. A red shadow runs again and its record is looked up again; a repeat turns the `step` path off, files GOH.REUSEOFFSTEP, and every later hit runs. This is the kill switch GOH_PROVEN_CLOSURE's flip to `on` waits on (GOH.REUSEAUDIT2).
- Each test gets its own reuse store (`GOH_REUSE_DIR`, `tests/host_locks.py`): the audit counts hits there, so a shared one made which hit a test's gate re-ran depend on the tests before it.
