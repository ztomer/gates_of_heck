* Land verdicts: a gate run whose every collected test was deselected as already passed (reused from the pre-land run, or carried from a recorded tree) and nothing failed exits 0, not pytest's 5 ("no tests ran"), and records a whole run as `full`. The v0.130.0 release gate deselected all 5812 tests and failed the ship on exit 5. It counts only nodes this run collected and deselected (under xdist each worker reports its count to the controller), so an empty collection with nothing deselected still exits 5 (`tests/test_land_verdicts.py`, serial and xdist).
