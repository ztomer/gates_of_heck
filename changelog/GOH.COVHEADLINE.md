* gates: a coverage run that a failing test starved headlines the test, not the floor: `goh_step` lets a step name its own cause (a line in the file `GOH_STEP_HEADLINE` names, shown instead of `<label> failed (...)`), and `coverage_gate.sh` writes `coverage: N test(s) failed under coverage (<first name>) -- not measured` there when tests starved the run, so the land log's `✗` line is `rust: coverage: 2 tests failed under coverage (cov::first_red) -- not measured` rather than `rust: coverage (floor 95%) failed`; a real below-floor result keeps the floor wording. Also `Gate.finish` and the gate-slot consumer tests' waits scale by `patience()` (a fixed 60 s timed out at load ~77, 16 s alone) (GOH.COVHEADLINE)
