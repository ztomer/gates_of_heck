* GOH.WORKERFAILS (part two): the Linux worker's image carries cargo-audit 0.23.0, swiftlint 0.65.1 (its static Linux build) and lsof, each at the Mac's release and checksummed. A test now holds that every tool the structural, goh-suite and rust layers refuse to run without is in the image's version record.
* GOH.WORKERFAILS: `goh remote-shard` clones the RustSec advisory database (shallow) into the worker's HOME when it is missing or a day old, using a short-lived networked container. The suite's offline rust-gate audits read that copy; without one they failed with "couldn't fetch advisory database". Release tags now travel with the synced tree, and a worker tree whose tags differ from the Mac's is sent one whole bundle. The tree sync no longer passes the BSD-only tar flags (`--no-mac-metadata`, `--no-xattrs`) to GNU tar.
* GOH.WORKERFAILS: `tools/quiet.sh` sorts its busiest-process list with sort(1), because procps `ps` refused the BSD `-r` flag.
* GOH.WORKERFAILS: these tests no longer assume the Mac. The update_dev tests are declared macOS-only, since the kit installs a .app bundle. The container-init owner test uses the top of its own process tree, which under `docker exec` is the child of the runtime's shim, not pid 1. The no-pidfd fake takes the real `(pid, flags)` arguments. The NO_COLOR test opens its own pty instead of running BSD script(1). The goh_init sentinel test uses a plain `exit 0`, which reaches the sentinel on every bash. The manifest's brew-route tests pin `GOH_TOOLS_OS=Darwin`. The self-hosted hook test passes RUSTUP_TOOLCHAIN through and puts /usr/local/bin on PATH.
* GOH.WORKERFAILS: `goh remote-shard` no longer replaces the worker container while any slot's run is in flight. Two lanes with different Dockerfiles share the container's name, and a replacement killed a full-suite run at 99%; the shard now runs locally and says why. In the image, `stable` names the pinned toolchain too, so a child that gets only PATH and HOME does not try to sync it into the read-only RUSTUP_HOME.
* GOH.WORKERFAILS: on Linux, where sysctl has no kern.sleeptime, `lib/sleep_mark.sh` gives a blank mark. Under pipefail the failing lookup used to stop `gates/round.sh` with exit 1 and no message. The load backstop (`lib/load_reap.py`) reads CPU time from /proc where it exists, because procps `ps` prints whole seconds and a sub-second burn read as none.
* GOH.WORKERFAILS: `gates/path_invariance.py` symlinks a second spelling of the tree on a host that has no alias of its own, such as Linux, where /tmp is not a symlink. A gate keyed on the spelling of its path is now caught there too; before, it passed under two separate clones.
