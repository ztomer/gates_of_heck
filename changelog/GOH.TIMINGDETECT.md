* GOH.TIMINGDETECT: `tests/test_timing_bounds.py` reads each test file's AST instead of a text pattern to find an elapsed time bounded by a literal. A duration is a clock's difference, any name the file binds to one (so `secs = time.monotonic() - t0` returned from a helper and asserted `secs < 10` is seen), a conventional name or an `["ms"]` field; an upper bound from either side of a comparison (`10 > secs`) counts, a lower bound does not, and ten minutes or more is a hang guard or a plausibility window (`tests/stamp_age.py`'s -5..600 s), not a box-tuned bound.
