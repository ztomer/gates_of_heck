* GOH.ADMITOKLINE: the Bash guard refuses a command whose `# x-ok: <reason>` escape (any of them: `admit-ok`, `quit-ok`, `discard-ok`, `load-ok`, `secrets-ok`, `reset-ok`, ...) is followed on its line by more command (`;`, `&&`, `||`, `|`, a background `&`), naming the text the comment swallowed. The escape is a shell comment, so a lane's restore step written after `# admit-ok:` on the same line silently never ran. The escape last on its line, or the rest on its own line, admits as before (`lib/escape_line.py`, asked first by `hooks/claude/discard_guard.py`).
