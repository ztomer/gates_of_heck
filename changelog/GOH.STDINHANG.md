* The Bash guard refuses a stdin reader nothing feeds (GOH.STDINHANG): `cat` with no file operand, `tee`, `read`, `python3 -` and `sh -s` with no heredoc, here-string, pipe or `<` on that command (or on the compound command around it). The Bash tool feeds `< /dev/null` unless the command holds a heredoc, and then fd 0 is the harness's socket, which never closes: `cat > /tmp/x.py` beside a `python3 - <<'EOF'` hung 5h51m on 2026-11-15. Escape: `# stdin-ok: <reason>`. Rule: `lib/stdin_reader.py`.
* The shell splitter no longer reads a here-string (`<<<`) as a heredoc opener: its word was taken as a delimiter and every command after it was swallowed as a body, unjudged (`lib/secret_render.py`).
