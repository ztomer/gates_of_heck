* `goh goh-pins` judges a goh action used by reference (GOH.WFPINACTION): `uses: OWNER/gates_of_heck/.github/actions/goh-floors@<commit> # vX.Y.Z` is judged on the release named beside it, `@vX.Y.Z` as written, and a commit naming no release or a branch is unpinned; the shape table's gap row is covered. `goh wf-pin --bump` moves such a pin's commit and its release comment together to the new release's commit, so the ship's sweep keeps all six consumers that use goh-floors by commit current. homebrew-tap (v0.71.0) and monitor (v0.96.0) were moved to v0.149.6 through their own gates.
