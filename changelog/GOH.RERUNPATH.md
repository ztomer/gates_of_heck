* **The scoped cache's read check resolves a relative path where cargo does, so a read outside the scope is no longer skipped (GOH.RERUNPATH).** `goh rust-scope --check-depinfo` joined every relative path to the directory its record sits in, inside the build dir, where it was ignored. Probed on cargo 1.100.0: a build script's `rerun-if-changed` is relative to its package root (cargo re-ran on `../outside.txt` beside the package and ignored the same name beside `run/`), and rustc's dep-info is relative to the workspace root, where cargo runs rustc (`pkga/src/../../other/inc.txt` for an `include_str!`). Both now resolve there, with `..` folded by name, so a missing file cannot pass as inside a covered directory; a record whose package `cargo metadata` does not name is reported rather than guessed (`crates/goh/src/rust_depinfo.rs`). On the probe workspace the check now names `other/inc.txt` and `outside.txt` and exits 1 where it passed before.
