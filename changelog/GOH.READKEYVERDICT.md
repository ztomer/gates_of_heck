* GOH.READKEYVERDICT: a test's green verdict is reused while what it reads is unchanged, at the land's pre-step too. The enqueue's (and a lane's) recording run of `tools/affected_tests.py --run` now carries from the one verdict store as the land gate's suite does (`carrying`: `GOH_LAND_VERDICTS_REUSE=/dev/null`, the pre-step's own run): a chosen test that passed on an earlier tree of the branch or on main's recorded tip is not run again when the selector, asked about the diff between the trees, does not choose it, so a run after a fix runs only the tests that fix's diff chooses. Every recording run now watches what each test file opens or lists under the tree (`tests/_read_audit.py`, an audit hook in each worker), keeps it in the tree's record (`reads`), and a carry refuses a node whose file read a changed path no rule of the selector declares, or whose reads were never watched: it runs, and the line names the test and the path. The gate's suite-once reuse (`lib/pre_reuse.py suite`) counts what the pre-step carried onto the tree as carried, never as judged.
