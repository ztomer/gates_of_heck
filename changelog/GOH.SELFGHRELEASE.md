* **goh's own release makes its GitHub release again.** From GOH.SHIPKIT on, `tools/release_goh.sh` pushed main and the tag and created no GitHub release, so origin held about 105 tags with none and `gh release list` kept v0.95.0 as Latest. The kit now runs the consumer kit's release step after the tag push: every earlier release-less tag with a stanza is backfilled with `--latest=false`, then this tag's release is cut with `--verify-tag` from its stanza and read back. The step lives in one file, `tools/release-kit/gh_release.sh`, which `release.sh` now sources as well.
