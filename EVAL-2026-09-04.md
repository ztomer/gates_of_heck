# gates_of_heck evaluation — 2026-09-04

Fresh-eyes audit after v0.8.0. Every finding below was verified against the
tree (file:line given); nothing here is inferred from docs alone. Planning
only — no code changed. If kept, this file is input to the rule-#13 backlog,
not a second backlog; prune it once its items land or are rejected.

## Verdict

The core is sound: delegation model (one checkout, zero re-installs),
index-truth staged checks, fail-fast with output, red-proven regression
tests, and contracts that name their pins are all real and load-bearing.
The gaps are all of one shape: **things the gates do not see at all**
(unlinted bash, uncommitted secrets, uncovered Rust, untimed runs), not
things they see wrongly. Nothing below questions the architecture.

## Findings, ranked by impact x cost

### 1. Bash is the most-edited language and the only unlinted one
Python gets `ruff check` + `ruff format --check` on every run
(`gates/py_gate.sh:51-52`); bash gets nothing. Authors clearly use
shellcheck (directives in `gates/_common.sh`, `gates/local_ci.sh`,
`gates/coverage_gate.sh:357,367,433`) but no gate enforces it, so a
SC2086-class quoting bug can ship green through the very harness whose
purpose is catching what humans miss. Direction: `shellcheck
--severity=error` + `shfmt -d` over `gates/ hooks/ tools/ install.sh`,
red-proven both directions like every other checker. Cost: small.
Watch: shellcheck must exist on the machine — missing binary is exit 2
with install hint (house rule: named refusal, never silent skip).

### 2. Rust has no coverage floor in its gate
`py_gate.sh` and `swift_gate.sh` both enforce floors
(`GOH_PY_COV_MIN`, `GOH_SWIFT_COV_MIN`); `rust_gate.sh:34-40` runs
fmt + clippy + allow-check and stops. `coverage_gate.sh --lang rust`
exists (per-target lcov exports, CGU normalization) but nothing wires it
into the rust gate, so a Rust consumer is one uncommented line away from
a floor and nothing tells them. Direction: either wire it behind
`GOH_COV_FLOOR_RUST` like the swift gate wires its helper, or document
in `docs/config.md` why Rust is exempt. Cost: small.

### 3. No secrets-leak gate
Verified: every `secret|token|api.key` hit in `checks/` and `gates/` is
benign (tokenizers, arg tokens). Nothing scans staged files for
high-entropy blobs or known prefixes (`ghp_`, `sk-`, `AKIA`, private-key
headers). One committed token dwarfs every other defect class this repo
gates. Direction: small dedicated checker (known-prefix regexes first;
entropy second, tuned for FP rate on this tree before enforcing), staged
scope like the emoji gate. Cost: medium (FP tuning is the work).

### 4. Swift coverage is implemented twice
`checks/check_swift_coverage.py` (legacy helper behind `swift_gate.sh`)
and `gates/coverage_swift.py` (engine behind `coverage_gate.sh --lang
swift`) overlap; `docs/map.md` documents which to touch, which treats the
symptom. Direction: unify behind one engine with characterization tests
 byte-pinning current outputs first (the lcov history — phantom misses
from naive aggregation — says untested merges lie). Cost: medium.

### 5. `.gatesrc` is sourced as shell in 5 places
`gates/structural.sh:45`, `rust_gate.sh:28`, `swift_gate.sh:43`,
`py_gate.sh:35`, `local_ci.sh:87` all `.` the file — a malicious
`.gatesrc` in a cloned repo executes on gate run. Current blast radius
is ~zero (all consumers are the user's own repos, same trust as hooks).
Direction: record the trust model in `docs/contracts.md`; only build a
KV parser if gates ever run against untrusted checkouts. Cost: tiny.

### 6. Small UX bundle: timeouts, --help, doctor
- `local_ci.sh` steps have no per-step timeout (python has `killtree.py`;
  bash has nothing) — one hung step hangs the run silently.
- Only `local_ci.sh` has `--help`; `install.sh`, `tools/gate.sh`,
  `structural.sh` do not.
- No `doctor` command: when delegation breaks (wrong `GOH_DIR`, hooks
  pointing at a deleted checkout), consumers debug by reading hooks.
  A `gate.sh --doctor` printing resolved paths + hook targets would end
  that class of confusion. Cost: small, all three.

### 7. No timing instrumentation
The 15s disk-hygiene cost was found by hand-timing with `time(1)`.
`goh_step` could print per-step elapsed with `GOH_TIME=1` (off by
default, zero overhead otherwise), so the next regression announces
itself. Cost: tiny.

### 8. Rule #13 mandates a backlog file; none exists
`docs/` holds five guides, no forward-looking backlog. Open items that
should seed it: launchd schedule for `disk_hygiene.sh`, finding-4
unification decision, finding-2 wiring decision. Cost: tiny (this file
is the seed; delete it once transferred).

### 9. Suite still has a 28s serial tail
`test_real_swiftlint_ratchet_green_then_red` (28s, shells real swiftlint
twice) dominates the 40s parallel suite. Direction: split
slow-toolchain tests behind a `-m slow` marker so the default run stays
fast and pre-push runs the full set. Cost: small.

### 10. `lib/mcp_scaffold.py` sits at 496/500 lines
The next feature edit trips the cap and forces a split mid-change.
Direction: pre-split now (small, calm diff) or record the exemption
reason before it bites. Cost: small either way.

## Checked and fine (explicit non-findings)
- Staged/index semantics, hook delegation chains, `GOH_DIR` fallbacks.
- Tap/release tests are hermetic (local artifact file, fake gh) — the
  only network-shaped risk does not exist.
- xdist grouping (`release`, `desk`) covers the only two shared-state
  hazards found by parallelizing.
- `GOH_*` schema drift gate holds (31 keys, all documented).

## Rejected (tempting, evidence says no)
- Rust rewrite of the gates: measured 0.45s of Python vs 15s of `du`
  stat-storm and 168s of subprocess spawns; it would speed up the
  wrong 3%.
- Caching `du` results across runs: staleness in a ceiling check is a
  silent pass — the failure mode this repo exists to prevent.
- Merging the coverage helpers without oracle tests: the phantom-miss
  history proves untested merges lie about percentages.
