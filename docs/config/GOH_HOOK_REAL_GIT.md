# GOH_HOOK_REAL_GIT
Area: runtime
Kind: internal
Order: 290
Default: set by `goh_hook_unbind` (`gates/_git_env.sh`)

The git `lib/hookgit/git` execs: while a hook carries an index that shim is first on PATH and binds
it for an index read in the committing repository (GOH.PATHSPECCOMMIT). Not a setting.
