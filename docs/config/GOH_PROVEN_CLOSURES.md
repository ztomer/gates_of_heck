# GOH_PROVEN_CLOSURES
Area: runtime
Kind: internal
Order: 360
Default: set by `gates/_proven_closure.sh`

Each step's goh closure line (`lib/step_closure.py`: the content of the goh files that can decide
that step, or `closure full`), one `<line>\t<step>` per step, computed once per gate for its steps
(GOH.PROVENCLOSURE). Not a setting.
