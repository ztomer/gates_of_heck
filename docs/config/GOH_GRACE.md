# GOH_GRACE
Area: structural
Kind: setting
Order: 370
Default: unset

A TEST SEAM for a week of grace (`crates/goh/src/grace.rs`, GOH.BAREOPEN2, GOH.FLOORREQ,
GOH.LINEHEDGE): a new scanner shape, or a scanner floor left undeclared, would turn a consumer red
the day goh ships, before any seed could name it (the seed lives in the owner's private store, which
a CI runner cannot read and the previous release reads as stale). Until 2026-11-23 the bare-open
shapes (`env`/assignment prefix, `$( )` inside double quotes, a Python subprocess), a plural hedge
after a string's backslash continuation, and an undeclared floor read as the last release did (the
floor an advisory line); from then they are judged. `goh dead-port` has its own end, 2026-12-07
(`deadport::OVER_FROM`, `grace::over_from`: it landed while goh's ships were frozen), under the same
seam. `over` in the AMBIENT environment makes them judged whatever the day, `within` makes them
advisory whatever the day. goh's own suites set `within` (`goh_testkit::goh_at`,
`tests/suite_home.py`: their fixtures are keyless); the suites that judge the new behaviour set
`over`. A scanner that judges nothing within the grace (`git-deadline`, `tui-marks`, `layer-parity`,
the floors) never loads its seed then either, so an entry written the week before is neither stale
nor settled (GOH.GRACEEND); a scanner that holds back only some shapes (bare open, plural hedge,
release quiet) judges its seed by today's shapes, so the entries for its new shapes are written the
day the grace ends. A repo cannot set it: the declaration is `.gatesrc`, never the environment the
gate was started in.
