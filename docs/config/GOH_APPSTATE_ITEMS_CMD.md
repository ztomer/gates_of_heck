# GOH_APPSTATE_ITEMS_CMD
Area: claude-hooks
Kind: setting
Default: the login items, by `osascript`

A test seam of `hooks/claude/appstate.py` and `app_quit.py`: the command that prints the login-item
app paths, one per line. Its words are split as a shell splits them and run without one. Under goh's
suite there is no default.
