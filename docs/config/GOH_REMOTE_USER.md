# GOH_REMOTE_USER
Area: remote-worker
Kind: setting
Order: 80
Default: `1000:1000`

`--user`: the non-root uid:gid the container runs as. The image names it (`goh`, home
`/work/cache/home`): with no passwd entry `Path.home()` under a test's dropped HOME raised
(GOH.WORKERFAILS); another uid here has no name in the image.
