# GOH_ACCOUNT_UNACCOUNTED_PCT
Area: runtime
Kind: setting
Order: 400
Default: 5

env, `lib/time_account.py` (`goh land-profile --account`, GOH.TIMEACCOUNT): the share of a group's summed wall (lands, ships) that may go unaccounted -- wall less every named phase -- before the account prints a FAULT line. A value that is no number is the default.
