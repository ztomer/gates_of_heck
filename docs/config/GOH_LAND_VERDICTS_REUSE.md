# GOH_LAND_VERDICTS_REUSE
Area: pushes
Kind: internal
Order: 260
Default: unset

Not a setting: that same file, given to the land's gate; the goh suite under it deselects every test
the record passed when the record's identity is this checkout's (`lib/gate_identity.py suite`: the
clean commit's tree and the tools), keeping, in the coverage step's instrumented run
(`GOH_COVERAGE_BIN_DIR` set), every test that ran the binary. It also CARRIES verdicts across trees
(GOH.VERDICTCARRY): every run under either key merges its passes into the one store's `carry` path
(`lib/reuse.py`: repo, tree, tools), and this run deselects a node another recorded tree passed --
the pre-step's commit (the record names it) and the nearest records on HEAD's first-parent chain --
when `tools/affected_tests.py`, asked about the diff between the trees, does not choose it; never
across a change to what every test loads, never a binary test across a build change or under
coverage. Each source is one use of the audited path (one in ten runs anyway as its shadow). The
header prints what each source deselected. `GOH_LAND_VERDICTS_RECORD=/dev/null` records the store
alone (a full run by hand, for `GOH_SHIP_FULL_SUITE`).
