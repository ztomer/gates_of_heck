# GOH_LAND_PRE_ALSO
Area: pushes
Kind: setting
Order: 150
Default: unset

A batch's other items' judged tips, space-separated: `tools/land.sh` writes them beside the gate's
record as `<record>.sources`, and the gate's suite carries verdicts from each of them as from the
tip's own (`tests/_land_verdicts.py` `_carry`, GOH.PREONTIP). Read once and unset. Internal: the
lander sets it.
