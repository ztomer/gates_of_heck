# GOH_LAND_GATE
Area: pushes
Kind: setting
Order: 20
Default: the kit's `tools/gate_profile.sh .` (by path)

The gate `tools/land.sh` runs on the branch tip before it fast-forwards the main checkout to that
SHA: the environment, else the repo's `.gatesrc`, else the kit's profile over the repo (its push
gate); tests point it at `true`/`false`.
